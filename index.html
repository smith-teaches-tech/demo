Ship it in 4 steps

  1. Push both files to your repo named demo.
  2. Settings → Pages → Source: Deploy from a branch → main / /root.
  3. Wait ~1 min, then open https://username.github.io/demo/.
  4. The game is at https://username.github.io/demo/asteroids/.

Or from the terminal

# from inside the demo folder
git add .
git commit -m "add homepage + asteroids"
git push

# every future push redeploys automatically

Because this is a project repo, every page sits under /demo/. Keep links relative (asteroids/, not /asteroids/) and they'll work both locally and once deployed.
