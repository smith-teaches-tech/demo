Ship it in 4 steps

  1. Create a repo named username.github.io (your exact GitHub username).
  2. Add this file as index.html in the root.
  3. Settings → Pages → Source: Deploy from a branch → main / /root.
  4. Wait ~1 min, then open https://username.github.io.

Or from the terminal

# start from a folder with index.html in it
git init
git add index.html
git commit -m "first deploy"
git branch -M main
git remote add origin https://github.com/username/username.github.io.git
git push -u origin main

# every future push redeploys automatically

Any repo works too — a repo named blog publishes at username.github.io/blog. Just flip on Pages in its settings.
